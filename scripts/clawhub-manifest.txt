# Every file publish-clawhub.sh is allowed to upload, relative to
# skill/postflight/. Paths only, one per line, LC_ALL=C sorted.
#
# publish-clawhub.sh already refuses the four shapes of personal file it knows
# by name (state/, *.local.md, .env, settings.json). It cannot refuse a shape
# nobody has thought of yet — a scratch note, an exported thread, a screenshot
# dropped in the skill folder and committed by accident. This list closes that
# gap: anything staged and not listed here fails the publish and fails CI.
#
# Adding a real skill file? Add its name here in the same commit. That one line
# is the whole point: publishing a new file becomes a decision someone made,
# not something that happened.
#
# This file lives in scripts/ rather than the skill folder so it never ships.
#
# Since v1.2.0 the published folder is also read-only at runtime: state and
# the user's *.local.md files live in <workspace>/postflight-state, outside
# anything an installer replaces. So this list is the whole skill, not the
# skill minus the personal parts, and publish-clawhub.sh greps the staged
# copy for docs still pointing at the old in-folder paths.
